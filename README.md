# Little Lights

Winter outings for Lower Mainland families: light walks, markets, skating, trains and parades, Dec 1, 2026 – Jan 31, 2027.

V1 is a single static page (`index.html`) with a hand-curated event list. Details were checked Nov 26, 2026; entries tagged "Check source" use last season's dates or prices.

## Deploy

Every push to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
